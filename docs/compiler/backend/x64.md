# x86-64 Backend Status

The x86-64 backend emits Linux ELF binaries and implements the same ownership
model as ARM64. Its reference-counting support covers fixed blocks, tagged
lists, dictionaries, closures, boxed sums, strings, and Blob buffers. The
remaining work is broader cross-backend coverage, not enabling reference
counting as a new subsystem.

## Ownership implementation

Fixed-block and boxed-sum release is driven by `RcShape` and `RcReleasePlan`.
New tuple, record, and sum shapes should extend that shared metadata and generic
executor rather than add a backend-specific matrix of helper names.

Tagged lists use an iterative traversal over the three allocated SkewList/RAL
node tags:

- `DIGIT` owns a complete tree and the remainder of the digit spine;
- `LEAF` owns one element payload; and
- `NODE` owns one element payload and two child trees.

Payload-aware helpers release managed elements in both leaf and internal nodes.
Nested list, dictionary, closure, fixed-block, and dynamic-buffer values are
selected through the release plan.

Dictionary helpers retain and release tagged HAMT roots and raw HAMT nodes.
Recursive key/value coverage is shallower than the list coverage, especially
for collision nodes containing nested managed shapes.

Strings and Blob values use the dynamic-buffer layout:

```text
[length:8][data:N][padding to 8][refcount:8]
```

Literal buffers use the immutable-refcount sentinel; heap buffers balance leak
accounting when their count reaches zero.

## Validation

Focused backend coverage lives in
`src/Tests/compiler-passes/X86_64CodeGenTests.fs`. Generated x86-64 ELF binaries
run directly on x86-64 hosts and through `/opt/dcb/qemu/qemu-x86_64` on other
hosts. End-to-end memory cases live under `src/Tests/e2e/`.

The remaining validation work is tracked in the [roadmap](../../project/roadmap.md):

- exercise both backends independently of host architecture;
- deepen recursive HAMT key/value and collision coverage;
- distinguish leak-counter balance from allocator reuse; and
- define the shared raw-memory ownership policy.
